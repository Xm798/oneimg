# 使用指南

完成[部署与首次登录](../README.md#首次登录)后，可以在上传页上传，在图库检索和整理。客户端集成见 [API 指南](api.md)，已有部署的兼容性变化见[升级指南](upgrading.md)。

## 图片上传与处理

在上传页先选择存储和标签，再通过文件选择、拖拽、粘贴或 HTTP / HTTPS 图片 URL 导入添加文件。文件先进入待上传列表，点击“上传全部”后开始；打开“添加后立即上传”则添加后直接上传。每批最多 10 个文件，每个文件独立显示结果，部分失败不代表整批失败；服务器返回的失败（如处理繁忙）可以单独重试。

- 在任意页面拖入或粘贴文件（输入框中除外），都会跳转到上传页并加入待上传列表；切换页面不会清空列表，退出登录或刷新页面会清空。
- 快捷键：`U` 打开上传页，`G` 打开图库。
- 格式或大小不符合要求、同一列表里重复的文件不会上传，并在列表中注明原因。服务器判定内容重复时标注“已存在”，返回已有文件的链接。
- 上传完成后可直接复制每个文件的链接，或选择格式后“复制全部”；所选链接格式保存在当前浏览器。

新增图片仅接受真实的 JPEG、PNG、GIF 和 WebP，不能通过修改扩展名上传 SVG 或未知格式。界面可设置图片大小、允许类型、压缩质量、WebP 转换、缩略图和跳过压缩格式；服务器还会执行独立的尺寸预算，默认最多 40,000,000 像素、单边 16,384 像素。

原图模式、跳过压缩和动画 WebP 同样需要通过格式和尺寸验证。有效动画 WebP 保留原始字节；无法识别尺寸或截断的文件会被拒绝。图像处理并发固定为 1，遇到处理繁忙时稍后重试，不要连续无间隔重发。

内容哈希用于识别重复图片。去重命中时复用已有记录，不重复增加数量。原始文件名作为元数据保留，新文件的物理名称带随机标识，不应依赖“同名上传会覆盖旧图”的行为。

URL 导入仅用于图片，且不能访问被禁止的内网地址。批量上传、大小限制与错误码见 [API 指南](api.md#上传图片或视频)。

## 视频上传与播放

在“系统设置 → 上传规则”打开“允许视频上传”后，可以通过文件选择、拖拽或 API 上传 MP4 / WebM。该功能默认关闭，启用后仍受用户上传权限与存储桶权限约束；关闭开关不会影响已有视频的播放、管理和统计。

- 视频大小限制独立于图片，默认 **100 MiB**，可设置为 **1 MiB～1 GiB**。
- 保存原文件，不转码、不压缩、不生成服务端封面，不需要 FFmpeg。
- URL 导入和 `import-local` 仍只处理图片。
- 容器格式不代表编码一定兼容。建议使用 H.264 MP4 或 VP9 WebM，实际能否播放取决于浏览器。

上传页和图库显示视频占位卡片，点击后通过浏览器原生控件播放，加载元数据后显示时长和分辨率。应用代理支持 `HEAD` 和单段 `Range` 请求；独立直链或 CDN 也必须支持 Range，才能按需读取和拖动播放。

## 存储与访问

可使用本地、S3/R2、WebDAV 或 FTP。管理员配置存储桶并分配使用权限；普通用户只能选择自己有权使用的桶。访问域名在存储页设置：本地存储可配置 CDN 域名（CDN 回源指向 `uploads` 目录，链接去掉 `/uploads` 前缀）；每个 S3/R2 存储可单独配置直链域名，设置后它的全部文件（包括历史文件）都返回这个域名的链接。FTP 和 WebDAV 始终经 OneImg 访问。

浏览器直接访问 CDN 或直链域名，请求不经过 OneImg，来源白名单对这些链接不生效；需要防盗链时在 CDN 或存储服务一侧配置。

### 存储路径与文件名

“系统设置 → 上传规则”中的存储路径和文件名对所有存储生效，只影响新上传的文件。存储路径可以选常用方案（按年 / 月、按年 / 月 / 日、按角色分开、不分目录），或选“自定义”后用拼装器添加目录、切换到“直接编辑”手写；文件名在随机名、原文件名和自定义模板之间三选一。可用变量为 `{year}` `{month}` `{day}` `{hour}` `{minute}` `{second}` `{role}` `{random}` `{uuid}` `{filename}`，区分大小写；存储路径不能包含空格、`\`、`.` 或 `..` 目录。

输入有误时页面会指出原因并提供“修正”，修正前不能保存。

本地存储的文件始终放在 `uploads` 目录下，路径不以 `uploads` 开头时自动补上，以保证文件位于持久化目录内、本地 CDN 域名也能生效。S3/R2 等远端存储按原样使用配置的路径。文件名除单独使用 `{random}` 或 `{uuid}` 外，都会自动加上 `-随机ID`，避免重名。

### 停用与删除存储

不再向某个存储上传时，优先使用**停用**：停用后它不出现在上传选项中，上传和 URL 导入都会被拒绝；已有图片、外链、授权和远端文件保持不变，可随时重新启用。本地存储和当前系统默认存储不能停用，需先在存储页顶部切换默认存储。

**删除**会移除该存储的全部图片记录、标签关联和用户授权，外链随之失效，且无法撤销。删除时默认保留远端文件，便于自行备份或迁移；只有勾选“同时删除远端文件”（API 为 `purge_objects=true`）才会清理其中未被其他记录引用的源文件和缩略图。当前系统默认存储同样不能删除。

更换远端端点或账户时，需要显式提供新凭证。引用已有配置进行连接测试还要求 `storage:update` 权限，只有新建权限不等于可以使用已保存的凭据。

数据库记录与物理对象需要共同备份。删除记录时，应用会检查历史共享对象的主图 / 缩略图引用，不能手工删除某个物理文件来代替图库管理。覆盖与删除保护的边界见[对象与存储兼容性](upgrading.md#对象与存储兼容性)。

媒体外链用于公开读取；管理界面的登录和权限不等同于私有媒体访问控制。来源白名单也不能代替身份认证，分享前应确认内容可公开。

## 标签与搜索

图库可以组合使用媒体类型、存储桶、标签和未分类筛选，并按文件名、URL 或内容哈希搜索。管理员还可按上传者角色筛选。筛选条件保存在地址里，可以收藏或分享给有权限的人。

- 标签按使用次数排序，侧栏默认只显示最常用的 8 个，标签多时可以搜索或展开全部。次数按当前账号能看到的文件统计。
- 点击文件打开详情：复制各种格式的链接、添加或移除标签、查看文件信息、下载或删除。双击或点“放大查看”进入全屏查看器，可以缩放（滚轮、双指、双击、`+` / `-` / `0`）、拖动和左右切换；视频直接播放，无法播放时提示原因。
- 勾选文件后可批量复制链接、添加或移除标签、删除；可用操作取决于当前账号权限和资源归属，无权处理的文件会跳过。
- 侧栏标签区的齿轮按钮打开“管理标签”：新建、重命名、删除，以及用“未使用”筛选后一次性清理。删除标签不会删除文件。原来的 `/tags` 地址会打开这个面板。

标签管理的权限与给文件添加 / 移除标签的权限分别检查。标签名称为 1–10 个字符。

## 复制外链

上传结果、全屏查看器和图库都可以复制链接，所选格式保存在当前浏览器；图库可批量复制：

| 格式 | 图片 | 视频 |
| --- | --- | --- |
| URL | 直接链接 | 直接链接 |
| Markdown | 图片语法 | 普通链接，不是图片语法 |
| HTML | `<img>` | 带 `controls` 的 `<video>` |
| BBCode | `[img]` | `[url]` |
| 动图式 HTML | 普通图片 | 静音循环、自动播放的 `<video>` |

视频不能用 `<img>` 或 Markdown 图片语法嵌入。接收方站点是否允许 `<video>`、自动播放及跨域资源，仍取决于该站点与浏览器的规则。

## 统计口径

统计页显示文件数量与体积、今日和本月上传、上传趋势，以及格式和大小分布。管理员看到全站数据，普通用户只看到自己上传的文件。上传趋势可按日（最近 30 天）、周（最近 12 周）、月（最近 12 个月）或年（最近 5 年）查看，也可以切换成表格；日期按服务器时区划分。

- 图片数量与视频数量分开显示；API 的 `total_images` 只计图片，`total_videos` 计视频。历史缺少 MIME 的记录继续归为图片。
- 图片体积只计主文件，视频体积只计原文件，不含缩略图；存储桶占用包含成功保存的缩略图。
- 今日 / 本月上传附图片与视频分类；趋势中的 `count` 为两类合计，另有 `image_count`、`video_count`。
- 数量按当前记录统计，去重不重复计数，删除后会减少。记录口径不等于底层物理对象去重后的磁盘占用。

## 用户与系统设置

- **用户**：管理员可以新建用户、修改用户名和角色（需要“修改用户名和角色”权限）、设置功能权限（只对管理员生效）和普通用户可用的存储。超级管理员和自己不能在用户页修改，自己的资料在账户设置中修改。
  - 只能管理普通用户和权限少于自己的管理员。管理其他管理员需要比对方多至少一项权限；权限相同的管理员不能互相管理，列表中显示“无权管理”。
  - 只能授予自己拥有的权限；创建管理员需要“修改用户名和角色”权限。
  - 重置密码会生成一次性显示的临时密码，该用户首次登录必须修改密码；其会话、API 令牌和 Passkey 全部撤销。怀疑账号被盗用时，重置密码即可，Passkey 会一并撤销。
- **系统设置**：各分区的修改先暂存，由页面底部的保存栏统一保存或放弃；有未保存修改时离开页面会提示。保存时只提交改过的项目，全部成功才生效：任一项被服务器拒绝时所有修改都不保存，页面切换到出错的分区并标出原因。
- **账户设置**：修改用户名（仅管理员）或密码都需要当前密码，保存后需要重新登录。Passkey 和 API 令牌在同一页管理；新令牌只显示一次。
- **头像**：在账户设置顶部上传 JPEG、PNG、GIF 或 WebP 静态图，原图不超过 10 MiB。服务器会居中裁成 256×256 的 WebP 并去掉原图元数据，头像保存在数据目录，不占用存储配额，也不出现在图库和统计中。更换或移除头像、删除用户时，旧头像文件一并删除；没有头像时显示用户名首字母。头像只对本人和有“查看用户列表”权限的管理员可见。

## 导入历史本地图片

`import-local` 将现有 `uploads` 下的图片登记到图库，不移动或重命名原图，也不改变原始主文件 URL。只扫描 JPEG、PNG、GIF、WebP，跳过缩略图目录；新增缩略图使用独立随机名称。导入仍受图片大小、格式和尺寸限制。

先备份 `data` 和 `uploads`，确认目标用户 / 存储桶，再停止正常服务，避免两个进程同时写数据库和存储。以下示例适用于[现有 Compose 部署](deployment.md#使用-compose-部署)，使用与正常服务相同的镜像版本：

```bash
docker compose stop oneimg
docker compose run --rm --no-deps oneimg ./main import-local --root /app/uploads --dry-run
```

核对预览统计后再正式执行，完成后恢复服务：

```bash
docker compose run --rm --no-deps oneimg ./main import-local --root /app/uploads
docker compose start oneimg
```

`--dry-run` 不写导入记录或缩略图，但命令仍会先执行应用初始化和启动迁移，不是整个应用的只读模式；需要完全隔离时，应对备份副本操作。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--root` | `./uploads` | 历史本地图片根目录；容器内通常为 `/app/uploads` |
| `--user-id` | `1` | 图片归属用户，确认该用户存在 |
| `--bucket-id` | `1` | 对应本地存储桶，不用于导入远端桶 |
| `--date-source` | `mtime` | `mtime` 使用文件时间，`path` 尝试目录年月日并回退到文件时间，`now` 使用当前时间 |
| `--update-existing-date` | 关闭 | 更新已入库图片的时间，先配合 `--dry-run` 核对 |

已有记录一般跳过；缺失的哈希、原始文件名或原始大小可能被补全。退出码非零时检查失败计数和日志，不要假定全量导入成功后直接清理原文件。
